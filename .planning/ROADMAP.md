# Roadmap: Obsidian Knowledge Base

## Milestone: v1 Knowledge Base

### Phase 1: Vault Foundation
**Goal:** Reorganize vault, establish schema, taxonomy, and documentation.

**Requirements:** VAULT-01, VAULT-02, VAULT-03, SCHEMA-01, SCHEMA-02, SCHEMA-03, TAX-01, TAX-02, TAX-03, DOC-01, DOC-02

**Success Criteria:**
1. Old content archived, new folder structure in place
2. _taxonomy.md exists with seed categories and proposal staging
3. DECISIONS.md captures all design rationale
4. Note template ready for use

### Phase 2: Claude Code Skills
**Goal:** Build skills for capture, processing, search, and taxonomy management.

**Requirements:** SKILL-01, SKILL-02, SKILL-03, SKILL-04, SKILL-05, SKILL-06

**Success Criteria:**
1. /kb:add creates properly formatted inbox note
2. /kb:process fetches content, summarizes, and tags with confidence-based auto/ask flow
3. /kb:retag finds and updates notes after taxonomy changes
4. /kb:search returns relevant results via MCP
5. /kb:taxonomy displays current state and manages proposals

### Phase 3: Obsidian Views
**Goal:** Create Bases views for browsing and managing KB.

**Requirements:** VIEW-01, VIEW-02, VIEW-03

**Success Criteria:**
1. Inbox view shows unprocessed notes
2. All-notes view with sortable/filterable columns
3. Tag-grouped view for browsing by interest area

### Phase 4: Migration
**Goal:** Port existing relevant notes to new schema, archive the rest.

**Requirements:** MIG-01, MIG-02

**Success Criteria:**
1. Relevant notes identified, converted to new schema with proper tags
2. Remaining notes in Archive/
3. No content lost
